# Reports and Outputs

This directory contains reports, visualizations, and analysis outputs.

## Subdirectories

### figures/
Generated visualizations and plots:
- Time series plots
- Change point visualizations
- Posterior distribution plots
- Event impact charts
- Dashboard screenshots

### outputs/
Analysis results and data exports:
- Model summaries
- Change point estimates
- Impact quantifications
- Statistical test results

## Interim Report (Task 1)
- Planned analysis steps (1-2 pages)
- Event dataset summary
- Initial EDA findings

## Final Report (Tasks 1-3)
- Complete analysis methodology
- Change point findings with visualizations
- Quantified impact statements
- Dashboard functionality overview
- Limitations and future work discussion

## Report Format

The final report should be suitable for Medium or PDF publication:
- Professional formatting
- Clear section headers
- Embedded visualizations
- Narrative explanations
- Executive summary

## File Organization

Save outputs with descriptive names:
```
figures/
├── 01_time_series_overview.png
├── 02_change_points_detected.png
├── 03_posterior_distributions.png
└── 04_event_correlation.png

outputs/
├── model_summary.txt
├── change_points.csv
└── impact_quantification.csv
```
